- Sレイアウト44キーと66論理位置の対応
- キーコードのカテゴリ分類、カテゴリ内検索、現在値のカテゴリ判定、値の重複検査
- macOS US配列向けキー、修飾付き記号、F13〜F24、システム操作キーのHID値
- Bindingの同値判定
- キー差分とレイヤー名差分
- 追加レイヤー差分と一時IDの実機IDへの置換
- Undo / Redo履歴
- Exportスキーマ生成
- Importの正常系・不正系
- MockクライアントのWrite成功
- MockクライアントのWrite失敗時にスナップショットを保持
- ElectronのSerial許可元制限
- macOSデバイス選択ラベル

- TypeScriptコンパイル
- ESLint

- Electron用静的レンダラーbuild

- Mockクライアント単体で読込、Write成功、Write失敗を自動確認する。

- Web SerialとRPCレスポンス変換、途中失敗時の`discardChanges`は、開発者ツールのログとデバイス再読込でも確認する。

## 実機受入

Chrome、Edge、またはMacアプリ版で以下を確認する。USB接続、キーマップ読込、およびポインター設定の保存・反映はMacアプリ版の実機で確認済み。キー書込を含む未確認項目は継続して確認する。

1. Central側をUSB接続する。
2. 「USBで接続」から対象シリアルデバイスを選ぶ。
3. デバイス情報とSレイアウトが表示される。
4. 現在の全レイヤーが読み込まれる。
5. 1キーを変更し、実機がまだ変わっていないことを確認する。
6. 差分画面からWriteする。
7. 対象キーだけが変わったことを確認する。
8. 電源再投入後も設定が残ることを確認する。
9. Export、変更、Importで元の下書きへ戻せることを確認する。
10. レイヤーを追加し、差分確認までは実機に反映されないことを確認する。
11. Write後に追加レイヤーが再読込され、追加レイヤーを参照するキーも動作することを確認する。
12. 4層追加後に「空きなし」となり、5層目を追加できないことを確認する。
13. 左右Centralの判定結果と使用ファームウェアをREADMEへ記録する。
14. Web版とMacアプリ版の両方で同じデバイスを読み込めることを確認する。
15. Caps Lock、Command / Option、US記号、F13〜F24、macOSシステム操作キーを一時レイヤーへ割り当て、想定した入力になることを確認する。
16. カーソル速度、スクロール速度、縦・横の反転を保存し、即時反映と電源再投入後の保持を確認する。

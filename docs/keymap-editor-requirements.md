# torabo-tsuki LP XS Keymap Editor 要件

## 目的

torabo-tsuki LP XS を初めて使うユーザーでも、実機に近い図を見ながらZMKキーマップを安全に編集できるローカルWebアプリを提供する。

## 対象

- torabo-tsuki LP XS（ファームウェア上の `S Layout`）
- 右手側トラックボール構成
- 左右どちらがCentralでも接続可能なUSB Studio RPC
- Chrome / EdgeのWeb Serial対応環境
- Apple Silicon Mac用のローカルElectronアプリ
- 個人利用。公開、認証、サーバー、テレメトリは対象外

## 初版の機能

1. Sレイアウト44キーの実機形状表示
2. レイヤー切り替えとレイヤー名編集
3. ファームウェアが予約した範囲でのレイヤー追加（初期6層 + 最大4層）
4. デバイスが公開するBehaviorとパラメーターの編集
5. キーコード検索、カテゴリ別選択、修飾キー（Ctrl / Shift / Alt / Command）の同時押し設定
6. macOS US配列向けのCaps Lock、記号、Keypad、F13〜F24、Command / Option、システム操作キー
7. カーソル速度、スクロール速度、縦・横スクロール方向の設定
8. Undo / Redo
9. 接続時状態を基準とした変更差分
10. 明示的な確認後の一括Write
11. JSON Import / Export
12. 未書き込み下書きのLocalStorage保存
13. USB接続、切断、再接続、エラー表示
14. Web版と同じ編集機能を持つmacOS `.app`
15. macOS上でのSerialデバイス選択と最小権限設定

## 安全要件

- キーを編集しただけではデバイスを変更しない。
- Write前に変更位置、変更前、変更後を表示する。
- 変更されたバインディングだけを送信する。
- レイヤー追加も下書きとして保持し、差分確認後にだけデバイスへ反映する。
- 途中失敗時はデバイス側の未保存変更を破棄し、再試行できるようにする。
- 未知のBehaviorは削除・置換せず、そのまま表示・保持する。
- Importデータはスキーマと値を検証し、不正なデータを適用しない。
- MacアプリはNode.js APIを画面へ公開せず、`file://`起点のSerial権限だけを許可する。
- 外部ページへの遷移、新規ウィンドウ、WebViewを許可しない。

## 初版の対象外

- Bluetooth接続
- 一般公開・ホスティング
- コンボ編集
- タイピングトレーナー
- ファームウェア配布
- PAW3222センサー自体のCPIとAML設定のランタイム編集
- Intel Mac版、一般配布用署名・公証、Mac App Store配布

## 実機受入条件

1. Central側へUSB接続できる。
2. デバイス名、Sレイアウト、レイヤー、Behaviorを読み込める。
3. 1キーの変更がWrite前に実機へ反映されない。
4. 差分確認後のWriteで対象キーだけが変更される。
5. 再起動・再接続後も変更が保持される。
6. Import / Exportで同じ編集状態を復元できる。
